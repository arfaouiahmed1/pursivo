# Security policy

## Supported versions

Security fixes are provided for the latest GitHub release. Alpha and beta builds are development software and may require a clean reinstall if an announced migration limitation applies.

## Reporting

Please use GitHub's private vulnerability reporting for `arfaouiahmed1/pursivo`. Include the affected version, Android version, reproduction steps, expected impact and any suggested mitigation. Do not include a real provider key, CV, backup or other personal data.

Do not open a public issue for credential disclosure, backup path traversal, signature/update verification, exported Android components, or private-file access vulnerabilities. Maintainers will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is available.
